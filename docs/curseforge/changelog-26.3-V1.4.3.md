## Dreamcraft 26.3 V1.4.3 - cleaner inventory

### Changed
- **Cleaner inventory:** no more purple arrows on the hotbar and armor slots, no profile bar ("NONE") under the
  inventory, no slot highlighting, no extra editor and settings buttons in the corner and no "continuous crafting"
  box. Inventory sorting stays: one Sort button and the sort hotkey still work, and auto refill still swaps in new
  tools and blocks (it just doesn't mark the slots any more).
- **No item swapping animation:** items move between slots instantly again (Smooth Swapping is switched off; you can
  turn it back on in its config).
- **WorldEdit:** the selection wand is now the **wooden hoe** instead of the wooden axe, so chopping trees with a
  wooden axe no longer selects blocks.

Same mods and quests as V1.4.2. Your worlds and quest progress are kept.

### Server
- Update the server pack too if you use WorldEdit on your server: the wand item is set in
  `config/worldedit/worldedit.properties`.
