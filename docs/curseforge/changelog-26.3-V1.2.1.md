## Dreamcraft 26.3 V1.2.1 - quest book hotfix

### Fixed
- **The quest book reacts to clicks again.** Minecraft 26.3 numbers the mouse buttons differently, and the quest book
  still expected the old numbers: a left click only moved the map. Quests did not open, the first prologue quest
  ("I am ready to dream") and the class choice could not be ticked, and rewards could not be claimed.
  Quest Icons 1.0.2 fixes this. Your quest progress is kept.

### Server
- Replace `mods/QuestIcons-1.0.1+26.3.jar` with `QuestIcons-1.0.2+26.3.jar` (or use the new server pack).

Thanks to everyone in the Discord who reported it and found the cause!
